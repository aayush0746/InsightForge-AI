# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and privacy of InsightForge AI seriously, especially regarding multi-tenant data isolation and API keys.

If you discover a security vulnerability:
1. **Do NOT open a public GitHub issue.**
2. Send details of the vulnerability to the project maintainers via email at: `aayushkumar0746@gmail.com`
3. Include:
   - Description of the vulnerability
   - Steps to reproduce or proof-of-concept
   - Potential impact

We will respond promptly and work on a fix as quickly as possible.
